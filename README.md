# 🍽️ Recipes Website

This is a dynamic recipe website built with **HTML**, **CSS**, and **PHP**. It includes user **sign-in** and **sign-up** functionality and displays a growing collection of delicious recipes.

## 💡 Features

- User authentication system (register/login with PHP & MySQL)
- Homepage built in `index.html`
- Responsive layout using CSS
- Easy-to-add new recipes
- Backend handled with PHP
- Database connection via MySQL

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript 
- PHP
- MySQL
